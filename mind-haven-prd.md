# HUG - AI-Driven Mental Health Companion
## Product Requirements Document (PRD)

### Executive Summary

**Project Name:** HUG  
**Tagline:** "Your 24/7 AI Mental Health Companion - Always Here, Always Caring"  
**Target Hackathon:** World's Largest Hackathon presented by Bolt (Voice AI Challenge)  
**Submission Deadline:** June 30, 2025  

HUG is a revolutionary web application that democratizes mental health support through conversational AI technology. Built on Bolt.new with ElevenLabs voice AI integration, it provides 24/7 empathetic mental health support, crisis intervention, and personalized wellness programs to address the global mental health crisis affecting over 1 billion people worldwide.

---

## 1. Problem Statement

### The Global Mental Health Crisis
- **Scale:** Over 1 billion people globally suffer from mental health disorders (WHO, 2022)
- **Access Gap:** 70% of people with mental health conditions receive no treatment
- **Cost Barrier:** Traditional therapy costs $100-300+ per session
- **Stigma:** 60% avoid seeking help due to social stigma
- **Availability:** Limited 24/7 crisis support and immediate intervention
- **Geographic Barriers:** Rural and underserved communities lack mental health professionals

### Current Solution Limitations
- **Existing Apps:** Mostly text-based, lack real-time conversation
- **Chatbots:** Robotic responses, no emotional intelligence
- **Therapy Apps:** Expensive subscriptions, limited personalization
- **Crisis Hotlines:** Long wait times, limited availability

## 6. Technical Architecture

### 6.1 Technology Stack (Bolt.new Compatible)

#### Frontend (Built on Bolt.new)
- **Framework:** React.js with TypeScript (Bolt.new native)
- **Styling:** Tailwind CSS (Bolt.new integrated)
- **Voice Interface:** Web Speech API for browser-based voice input/output
- **Real-time Communication:** WebRTC for voice streaming to ElevenLabs
- **State Management:** React Context API + useState/useReducer (lightweight)
- **Routing:** React Router for single-page application navigation

#### Backend Services (Bolt.new Integrated)
- **API Framework:** Node.js/Express backend (Bolt.new supported)
- **Database:** Supabase (PostgreSQL) for user data and conversation logs
- **Authentication:** Supabase Auth for secure user management
- **Voice Processing:** ElevenLabs API for text-to-speech and voice synthesis
- **AI/ML:** OpenAI GPT-4 API for conversation intelligence
- **File Storage:** Supabase Storage for user assets and audio files

#### Third-Party Integrations (API-based)
- **ElevenLabs:** Voice AI and speech synthesis (primary requirement)
- **OpenAI:** GPT-4 for conversational AI and emotional intelligence
- **Supabase:** Database, authentication, and real-time features
- **Entri/IONOS:** Custom domain management (hackathon requirement)
- **Netlify:** Application deployment and hosting (hackathon requirement)
- **Crisis Text Line API:** Emergency support integration
- **Geolocation API:** Location-based resource finding

### 6.4 Data Flow (Bolt.new Optimized)

1. **User Voice Input:** 
   - Web Speech API captures audio in browser
   - Audio converted to text locally or sent to ElevenLabs

2. **AI Processing:**
   - Text sent to OpenAI GPT-4 for emotional analysis
   - Crisis keywords detected using local algorithms
   - Personalized response generated based on user history

3. **Voice Response:**
   - GPT-4 response sent to ElevenLabs for voice synthesis
   - Audio stream returned and played in browser
   - Conversation logged to Supabase (metadata only)

4. **Data Storage:**
   - User preferences stored in Supabase
   - Conversation summaries (not full transcripts) saved
   - Progress metrics updated in real-time
